## 🗺️ The five units

| Unit | What you learn | Say it like this |
|---|---|---|
| **10** | **was / were** | *I **was** tired. They **were** happy.* |
| **11** | **worked / got / went** (past simple) | *I **played**. She **went** home.* |
| **12** | **I didn't … Did you … ?** ⭐ | *I **didn't go**. **Did you** go?* |
| **13** | **I was doing** (past continuous) | *I **was reading** at 8 o'clock.* |
| **14** | **I was doing** and **I did** together | *I **was walking** when it **started** to rain.* |

⭐ **Unit 12 gets extra attention in this course** — it has its own big step, its
own cheat-sheet page, and the longest quiz. That's because nearly everybody makes
the same mistake there. You won't. 😉

## 🧠 The big picture (read this once)

Think of the past like a **photo album** 📸:

- **was/were** = describing the photo (*"The sea **was** blue."*)
- **past simple** = one photo, one finished action (*"We **swam**."*)
- **didn't / Did you…?** = the same photo, but **saying no** or **asking**
  (*"We **didn't swim**." / "**Did** you swim?"*)
- **was doing** = a video clip, still playing (*"We **were swimming** at 3 o'clock."*)
- **was doing + did** = a video with a surprise in the middle (*"We **were
  swimming** when a wave **knocked** me over."*)

**One album, five ways to talk about it.** 📖
